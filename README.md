# Money Waster 🪙

Премиальный открытый веб-кликер с рейтинговой системой, соревнованием по странам и миром, поддержкой 10 языков и автономной архитектурой.

## 🚀 Live Demo в браузере
- **GitHub Pages:** https://smsv4.github.io/money-waster-app/
- **HTML Preview:** https://htmlpreview.github.io/?https://github.com/SMSV4/money-waster-app/blob/main/index.html

## 🎮 Возможности
- 👑 **Профиль игрока:** Никнейм (3-16 символов), выбор из 8 аватаров, 53 стран и 10 языков.
- ⚡ **Игровая механика:** Клик по кнопке WASTE списывает 1 монету и увеличивает Waste-рейтинг на 1.
- 💬 **Динамические цитаты:** Более 100 мотивирующих и статусных фраз на 10 языках, сменяющихся в реальном времени.
- 🏆 **Таблица лидеров (Leaderboard):** WORLD и COUNTRY вкладки, прогресс и расчет подъема.
- 🚫 **Paywall / Лимит монет:** Модальное окно при 0 монет (+100 / +500 монет).
- 🔊 **Звуки:** Web Audio API синтезатор.
- 💾 **LocalStorage:** Полное автосохранение.
